# Instagram-bot

Insta GC Bot for Render deployment.

## Structure
- main.py
- database.py
- requirements.txt
- templates/index.html

## Setup
1. Push to GitHub.
2. Render: Web Service -> Python 3.
3. Build: `pip install -r requirements.txt`
4. Start: `python main.py`
5. Ping with UptimeRobot to keep alive.
